Add-in: Legislative Report Router

New coordinator? Start with the coordinator tutorials, the 15-minute Quick Start — written for humans, printable. Administrators: the full documentation covers list schemas, permissions, parsing rules, and government-cloud setup.

Workflow

Setup is one-time. Pick your SharePoint site, create the lists, and add division routes (all guided, with pickers) — the add-in saves everything to your account and reconnects automatically on every email afterward, on any device.

  1. Open the Daily Bill Report and click Report Router — if the subject looks like a bill report, it parses automatically.
  2. Review each bill's divisions and routes → Preview → Publish (explicit confirmation required).

Use ✅ Test my setup (in Setup) any time to verify every connection.

Common issues

  • Unknown division — no active rule matches. Fix the division text, add an alias to the routing list, or exclude the bill.
  • Route has no tag — the post publishes without a mention; add the TeamsTagId (Settings → tag lookup) to mention the tag.
  • Duplicate protection — re-publishing a report skips bills already recorded as published in the audit list; only failures re-run.
  • Bills not detected — the bill number must appear alone on its own line ("HF935"). See the parser rules in the repository docs.

Privacy

No data collection — parsing and publishing run in your own Microsoft 365 session. See the Privacy Policy.
