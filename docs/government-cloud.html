Government cloud configuration

Endpoint configuration does not certify government-cloud operation. Validate authentication, required Graph APIs, hosting policy and a complete publication workflow in the target tenant before deployment.

The Settings → "Cloud environment" selector maps:

EnvironmentGraph hostSign-in authority
Commercialhttps://graph.microsoft.comhttps://login.microsoftonline.com
GCChttps://graph.microsoft.comhttps://login.microsoftonline.com
GCC Highhttps://graph.microsoft.ushttps://login.microsoftonline.us
DoDhttps://dod-graph.microsoft.ushttps://login.microsoftonline.us

Notes:

  • GCC runs on the commercial endpoints (it is a compliance boundary, not an endpoint boundary); GCC High and DoD use the .us sovereign endpoints.
  • GCC High/DoD require a separate application registration in the sovereign cloud; a commercial multitenant registration cannot span national clouds. For a separate sovereign deployment, set CLIENT_ID in src/graph.js to that registration's client ID, configure the appropriate SPA/broker redirect for its host, and update manifest URLs if hosting changes. Selecting a cloud in the public deployment does not replace its commercial registration. See Microsoft's national-cloud authentication guidance.
  • Teams tag mention support and Graph feature parity can lag in sovereign clouds; if mentions with mentioned.tag is rejected, the post still succeeds without the mention and the audit row records the response.
